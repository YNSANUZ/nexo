# Arquivos complementares do Baixador oficial

Esta pasta contém somente os arquivos que precisam ser atualizados no aplicativo oficial já publicado em `/baixador/`.

- `instalar/index.html`: página de instalação com a versão atual do APK.
- `_next/static/chunks/292objnchc-s0.js`: componente da página de instalação correspondente à mesma versão.
- `downloads/Baixador-NEXO-Android-0.3.1.apk`: APK atual.
- `downloads/Baixador-NEXO-Android-0.3.0.apk`: cópia de compatibilidade para páginas antigas em cache.

A interface oficial permanece em `/baixador/`. O APK e a interface chamam o backend absoluto em `/baixa-nexo/api`.
